# cringe-site

The public website for the **cringe.** app: home page, privacy policy, terms of service and account deletion page. Plain HTML and CSS, no build step, hosted free on GitHub Pages.

| Page | File |
|---|---|
| Home | `index.html` |
| Privacy Policy | `privacy.html` |
| Terms of Service | `terms.html` |
| Delete your account | `delete-account.html` |

Live at: https://sanithakj1975.github.io/cringe-site/

## Editing

- Change text directly in the `.html` files. Colors and fonts are in `style.css`.
- The contact email appears in every page. To change it, find and replace it in all `.html` files.
- When the app is live, put its Play Store link in the "Coming soon on Google Play" button in `index.html`.
- Update the "Last updated" date on a page whenever you change its policy.

## Hosting

GitHub repo → **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)** → Save. The site updates about a minute after each push.
